# Work clock versus CPU-time verdicts

Contest solution variants and the verdict-disagreement analysis described in
[docs/JUDGE_DISAGREEMENT.md](../../docs/JUDGE_DISAGREEMENT.md). The variants and
their manifest are in `variants/`; `variants/check.py` verifies every output.
The counters and timings come from round 2 of the capacity-miss study
(`experiments/capacity_misses`), whose `analyze_v2.py` computes the verdicts.
