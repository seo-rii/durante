Freeze the nine Linux x86-64 CPP20 ELF/stdin/stdout triples before executing or timing any workload. No resizing or selection from timings. All random streams use xorshift32 (left 13, right 17, left 5, truncating to 32 bits after each shift/XOR).

Calibration uses one executable. Every case first fills the entire same aligned 16 MiB array of uint32_t with (2654435761*i+12345) modulo 2^32. Every ordinary-access loop makes 8388608 identical xorshift32 steps from seed 193177 and sums one table load per step, with index state AND a runtime mask. Masks select 1024, 262144, or 4194304 entries (4 KiB, 1 MiB, or 16 MiB). The mask changes the addresses and values, while the loop instructions and loads stay fixed. After this traversal, execute 32768 explicit REP MOVSB operations copying 0 or 8192 bytes between two separate aligned 8 KiB buffers beginning at the same address on each iteration. Thus aggregate explicit MOVSB lengths are 0 or 256 MiB. Inputs use the copy length and table size. Both buffers are initialized in every case. Output the 64-bit gather sum and the final destination byte at position 471. Whole-process measurement includes startup, deterministic initialization and all faults. The copy buffers fit simultaneously in a 32 KiB cache; these transfers represent warm repeated copies.

External sparse-rmq builds a range-minimum sparse table over 262144 xorshift32 array values and performs 2097152 seeded inclusive range queries with lengths 1..64, clipped at the right boundary. It reports the sum of minima. The oracle directly scans each requested interval.
External histogram-stack processes 128 independent 32768-bar histograms from a single seeded xorshift32 stream; heights 1..65536, width 1. Return the sum of the largest rectangle area in each histogram. The oracle activates bars by descending height and joins neighboring active components.
External distinct-window counts all contiguous subarrays with no repeated symbol in 8388608 pseudorandom values on a 262144-symbol alphabet. The oracle extends a queue and explicitly evicts symbols on a duplicate. All seeds and sizes are in the case inputs. Each external algorithm has one source, ELF and input.

Build using g++ (Debian 12.2.0-14+deb12u1) 12.2.0, with -std=c++20 -O2 -static -no-pie -march=x86-64 -mtune=generic -Wl,--build-id=none -s. In each per-case directory 'in' holds stdin and 'oracle' holds stdout. Compile crossed/main.cpp once for all six calibration cases. Each external case uses its own main.cpp.
